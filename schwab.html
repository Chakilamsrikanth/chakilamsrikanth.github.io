My work

My main focus at Charles Schwab was portfolio management. I worked across the Java backend and web interface, connecting the data, service behavior, and forms needed by the application. Much of that work involved making changes that were consistent across layers: an interface needed reliable data behind it, and an API needed to support the way the portfolio application actually used that data.

I built and refined backend functionality with Java and Spring Boot, using collections, streams, and lambda expressions where they helped keep data handling clear. I worked with other teams on REST APIs and microservice boundaries so portfolio related functionality could be integrated and maintained without treating the application as one large unit.

Database work was another important part of the portfolio management effort. I improved Microsoft SQL Server queries with indexing and stored procedures, working on the retrieval paths that fed the application. Alongside that, I introduced RabbitMQ for communication between services, helping the system handle work across those boundaries more reliably.

On the frontend, I developed reusable forms in React and Redux, including validation and shared interaction patterns. I worked with UI/UX designers to turn designs into HTML, CSS, and JavaScript interfaces. Reusing those pieces helped keep the portfolio application consistent as features changed, rather than solving the same form and state problems separately on every screen.

I supported the portfolio application through testing and delivery as well. That included JUnit and Mockito tests, integration checks across distributed components, and Splunk logs for investigating behavior. Deployments used AWS EC2, S3, and RDS, with Jenkins pipelines supporting delivery. I also contributed to the Developer API Portal, mentored junior developers, and reviewed code, with most of my attention remaining on the portfolio management application.

A smaller part of my work involved digital messaging, including its web interface and backend integration. The screens and walkthrough below are retained from my earlier portfolio; the chatbot image shows the AI related interface previously featured there.

Working with: Java, Spring Boot, React, Redux, REST APIs, Microsoft SQL Server, RabbitMQ, JUnit, Mockito, Splunk, AWS EC2, S3, RDS, and Jenkins.
