My work

At The Home Depot, my main focus was Python backend development. I built modular Flask services and REST endpoints, working on request validation, database access, and the separation of application logic. The goal was to make the backend easier to maintain while improving the reliability and response time of the workflows it supported.

I also worked on a Python and Oracle SQL application for operational reporting and sales forecasting. Scheduled jobs produced system availability reports, while machine learning supported the forecasting side. This connected the backend work to practical retail questions: whether systems were available and how historical sales information could support planning.

For deployment and reliability, I worked with Python services on GCP Compute Engine, together with Cloud Load Balancing, Logging, and Monitoring. I used test driven development and automated checks to validate changes, and wrote Bash scripts to help with deployments and log analysis. Agile planning and Jira helped keep that work connected to the wider team’s delivery process.

Security was part of the infrastructure work too. I configured SSL/TLS with OpenSSL and worked on VPC rules for Kafka clients and SQL databases so communication could be encrypted and access controlled. These changes supported the services rather than being treated as a separate final step.

Although Python was the center of my role, I also contributed to AngularJS and React interfaces using HTML, CSS, JavaScript, jQuery, TypeScript, and JSX. My earlier portfolio showed retail screens around purchase orders and shipment information, as well as work involving Java services, SQL data, and cloud migration. I have kept that walkthrough below to show the interface side of the work alongside the Python focused account here.

Working with: Python, Flask, Oracle SQL, REST APIs, scheduled reporting, machine learning forecasting, Bash, automated testing, GCP Compute Engine, Cloud Load Balancing, Logging, Monitoring, OpenSSL, VPC networking, Kafka, AngularJS, React, and TypeScript.
