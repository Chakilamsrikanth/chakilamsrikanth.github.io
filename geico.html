Modernizing policy and claims services with Go and Azure, while integrating LLM search, retrieval, and agent workflows.

My work

At GEICO, I worked on the services behind insurance policy management and claims automation. A large part of the work was moving functionality out of legacy Java applications into smaller Go services, while keeping the connections to existing systems working. We deployed those services in containers on Azure Kubernetes Service and used PostgreSQL for application data and Kafka for asynchronous communication.

I also worked on LLM powered search and policy lookup, including retrieval augmented generation and agent workflows. The aim was to make relevant policy information easier to find through the application. My role involved integrating those capabilities with backend APIs and connecting the AI interaction to the Go services and Azure infrastructure supporting the platform.

For that AI work, the supporting application flow mattered as much as the model interaction. I worked on secure ways for requests to reach backend services and on how retrieved information moved through the search and lookup experience. RAG and agent workflows brought together information retrieval and service integration, rather than sitting apart from the rest of the product.

On the service side, I built REST APIs using Go’s goroutines, channels, and middleware patterns. Azure API Management supported token based access, while Kafka topics carried events and supported log aggregation across services. I tuned PostgreSQL access through GORM and used Azure Functions to automate event driven steps in the backend workflow.

I also helped make the platform easier to operate. Grafana dashboards brought together Prometheus metrics and Loki logs so the team could follow latency, throughput, failures, and application health. Delivery and infrastructure work included Azure DevOps pipelines, App Services, Functions, and PostgreSQL. Those operational pieces were important for understanding how both the core APIs and the newer AI features behaved after deployment.

Working with: Go, goroutines and channels, Azure AKS, Azure API Management, App Services, Functions, Azure DevOps, PostgreSQL, GORM, Kafka, Grafana, Prometheus, Loki, LLM integration, RAG, and agent workflows.
