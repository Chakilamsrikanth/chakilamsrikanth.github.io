My work

At Oracle, I work on a SaaS application where the interface, backend services, and cloud infrastructure need to work together reliably. I help take features from the initial requirements through design, implementation, testing, and deployment. That means looking beyond an individual API or screen and understanding how a change affects the rest of the application.

A growing part of my work involves retrieval augmented generation, or RAG, and agent workflows. I work on connecting AI features with application services so they can use relevant information and fit into an existing product. My focus is the engineering around these capabilities: how context reaches the workflow, how services connect, and how access is handled alongside the rest of the application. I also build Python components and Model Context Protocol (MCP) tools that connect agent workflows with application services and information sources. This work includes defining tool inputs and outputs, validating requests, and handling service responses and errors.

With RAG and agents, I pay particular attention to the boundary between an AI workflow and the systems it interacts with. Retrieving information and coordinating service calls introduces a different set of concerns from a conventional request. I approach that work with the same attention to authentication, permissions, and application behavior that I bring to other backend features.

The application foundation is built with Java and Spring Boot on Oracle Cloud Infrastructure. I integrate backend services with OCI Compute and Object Storage, and use Identity and Access Management for authentication and authorization. I also contribute to architecture decisions around scaling and fault tolerance, keeping the cloud setup aligned with how the application is expected to run.

I work on infrastructure provisioning and delivery through OCI Resource Manager and CI/CD pipelines. After a feature is deployed, Grafana and OCI Monitoring help me follow application health and investigate performance issues. Being involved in both delivery and operations gives me a clearer view of what needs attention before the next release.

Working with: Java, Spring Boot, Python, MCP tools, Oracle Cloud Infrastructure, Compute, Object Storage, IAM, OCI Resource Manager, CI/CD, Grafana, OCI Monitoring, RAG, and agent workflows.
