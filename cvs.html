My work

At CVS Health and Aetna, I worked on the application services and web experiences behind pharmacy and health related workflows. The work covered requirements and architecture through implementation and testing, with Java APIs supporting the interfaces. I paid attention to exception handling and service behavior so that problems in one part of a workflow could be handled clearly by the rest of the application.

One of the more substantial backend improvements involved caching and access control for APIs used by Kotlin mobile applications. I combined Redis caching with OAuth2 authentication through Spring Security. That reduced repeated data retrieval work and helped cut retrieval latency by half, while keeping endpoint access controlled.

On the web side, I developed AngularJS interfaces with routing, lazy loading, and form validation, and worked from UI/UX mockups to build responsive screens. The existing portfolio also shows registration, sign in, shopping, and claims related interfaces. HTML, CSS, JavaScript, jQuery, and Bootstrap supported that work, alongside the Java and Spring based backend.

I integrated GraphQL endpoints with Node.js services and used TypeScript for clearer contracts in the web application. On the data side, Hibernate and Spring connected application logic to storage, with MongoDB sharding and caching supporting the growth of CRUD workloads. These were connected pieces of the same problem: getting the right information to the interface without adding unnecessary work to each request.

Claims visualization and cost estimation modules were containerized with Docker and deployed on Azure Kubernetes Service. Grafana and Prometheus helped monitor application behavior. The earlier site also documented AWS hosting for the Aetna work and Azure for CVS; the screenshots and both walkthroughs below preserve those examples without replacing them with generated healthcare screens.

Working with: Java, Spring, Spring Security, Hibernate, Redis, OAuth2, Kotlin-facing APIs, AngularJS, HTML, CSS, JavaScript, jQuery, Bootstrap, GraphQL, Node.js, TypeScript, MongoDB, Docker, Azure AKS, AWS, Grafana, and Prometheus.
